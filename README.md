# pharmacy

Приложение ОАО «Жар-птица» для демонстрационного экзамена, вариант 5.

Проект находится в папке [Pharmacy](Pharmacy). Запуск: `Pharmacy/run.cmd`.
Для запуска требуется .NET 10


В папке проекта доступны исходный код C# WPF, готовая сборка `Deliverable`, база SQLite, SQL-скрипт с импортированными данными, ER-диаграмма, блок-схемы и отчёт со снимками интерфейса.

Подробности и учебные учётные записи: [Pharmacy/README.md](Pharmacy/README.md).
